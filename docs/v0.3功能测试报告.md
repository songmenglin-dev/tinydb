## 四、Network Client（Python Client 库）

### 4.1 同步 Client（REQ-CLI-1..8）

```python
from tinydb.client import Client

c = Client('127.0.0.1', <port>, connect_timeout=2.0, heartbeat=False)
assert c.version == 'tinydb-0.3.0'                    # HELLO 后 server 返回版本  [PASS]

r = c.execute("INSERT INTO cli_t VALUES (1, 'alice')")
assert r.rowcount == 1 and r.last_insert_id == 0
assert r.rows == []                                   # INSERT 不返回数据行  [PASS]

r = c.execute("SELECT id, name FROM cli_t WHERE id = 1")
assert r.rowcount == 1 and r.rows == [[1, 'alice']]
assert len(r.columns) == 2                            # 列数正确（具体名 placeholder）  [PASS]

# execute_many 批量
total = c.execute_many("INSERT INTO cli_t VALUES (?, ?)",
                       [[i, f'u{i}'] for i in range(10, 20)])
assert total == 10                                    [PASS]

# transaction 提交 / 回滚
with c.transaction():
    c.execute("INSERT INTO cli_t VALUES (100, 'tx_commit')")
# 后续 SELECT → 可见                                      [PASS]

try:
    with c.transaction():
        c.execute("INSERT INTO cli_t VALUES (101, 'tx_rollback')")
        raise RuntimeError("force rollback")
except RuntimeError:
    pass
after = c.execute("SELECT name FROM cli_t WHERE id = 101")
assert after.rowcount == 0                            # 回滚生效（无可见行）  [PASS]

# ping / close / 错误处理
assert c.ping() * 1000 < 5.0                          # RTT < 5ms  [PASS]
c.close(); c.close()                                  # 幂等  [PASS]

# 死端口
try: Client('127.0.0.1', <dead>, connect_timeout=0.5, heartbeat=False)
except tinydb.client.ConnectionError as e:
    assert 'cannot connect' in str(e)                 [PASS]
```

### 4.2 异步 AsyncClient（REQ-CLI-3）

```python
import asyncio
from tinydb.client import AsyncClient

async def one_query():
    client = AsyncClient('127.0.0.1', <port>, connect_timeout=2.0)
    try:
        await client.connect()
        r = await client.execute("SELECT id FROM cli_t LIMIT 1")
        return r.rowcount >= 0
    finally:
        await client.close()

t0 = time.monotonic()
results = await asyncio.gather(*[one_query() for _ in range(50)])
ok_count = sum(results)
# 50 个独立 AsyncClient 并发：50/50 成功，116 ms（远低于 5s）  [PASS]
```

> **已知 spec gap**：单个 `AsyncClient` 不支持并发 `execute()`（共享 `StreamReader.readexactly`）。本测试用 50 个独立连接并行以满足 spec REQ-CLI-3 "50 个查询全部成功" 的语义；单连接流水线（pipelining）建议在 v0.3.1 实现（见 §十二）。

### 4.3 连接池 Pool（REQ-CLI-9）

```python
from tinydb.client.pool import Pool

pool = Pool('127.0.0.1', <port>, max_size=2, connect_timeout=2.0, heartbeat=False)
with pool.connection() as p1:
    p1.execute("SELECT id FROM cli_t LIMIT 1")
with pool.connection() as p2:
    p2.execute("SELECT id FROM cli_t LIMIT 1")
# id(p1) == id(p2)：归还的连接被复用，无新 TCP          [PASS]

p_a = pool.acquire(timeout=0.5)
p_b = pool.acquire(timeout=0.5)
try:
    pool.acquire(timeout=0.2)
    assert False, "应抛 TimeoutError"
except queue.Empty:
    pass                                              # 池满时第 3 个超时  [PASS]
```

## 十二、已知 Spec Gap（v0.3.1 待修复）

| Spec | 描述 | 现状 | 跟踪 |
|---|---|---|---|
| REQ-PROTO-4 | `QUERY SELECT 1`（无 FROM 子句）应返回 1 列 + 1 行 | v0.3 SQL parser 强制要求 FROM，spec example 未实现 | parser 扩展 |
| REQ-CLI-3 | 单 `AsyncClient` 应支持并发 `execute()`（pipelining） | 当前共享 `StreamReader`，多协程 readexactly 冲突；测试用 50 个独立连接兜底 | AsyncClient 协议层加 request_id |
| SELECT 列名 | 应返回真实列名（如 `name`/`id`）而非 `col0`/`col1` | v0.3 仍输出 placeholder（v0.1 POLISH-CLI 修过的回归） | executor 列名映射 |
| `AS alias` | spec REQ-PROTO-4 / REQ-CLI 隐含 | 当前 parser 在 `SELECT ... AS` 处报 `expected keyword FROM` | parser 扩展 |
| CLI exit codes | spec REQ-CLI-CS-1/2/8 要求 rc=2/2/3 | 实际全部 rc=1 | `cli/app.py` 错误码区分 |
| CLI 错误格式 | spec REQ-CLI-CS-3 要求 `ERROR 42000: ...` | 实际 `ParseError: ...`（本地 ParseError） | CLI 错误透传 |
| CLI 多语句 | `-c "A; B"` 当前报 "unexpected trailing token" | spec 未明确，但 v0.2 报告里 CLI 是单语句风格 | parser 接受 `;` 分隔 |

**结论**：v0.3 五个 ship 的核心能力（wire、server、sync client、pool、CLI、JDBC）100% 通过。**v0.3.1 hotfix 应优先修复上表 7 项 spec gap**，建议由 fix/ocr-high-v0.3 风格的小批量 commit 实现，每项附 regression test。
